No German voice is installed in this browser. The English voice is reading the German text, so "Vater" comes out with an English V instead of FAH-ter. Add a German voice (takes a minute), then reload this page:
Windows: Settings → Time & Language → Language & region → Add a language → Deutsch (Deutschland) → tick "Text-to-speech". Edge also has "Natural" German voices online.
Mac: System Settings → Accessibility → Spoken Content → System Voice → Manage Voices → German → download Anna or Petra.
Android / iPhone: Chrome or Safari use the phone's voices; add German under Settings → Accessibility → Text-to-speech (Android) or Spoken Content → Voices (iPhone).
Click any German word or sentence with the speaker icon to hear it. Pronunciation hints are approximate English respellings; CAPITALS mark the stressed syllable.
