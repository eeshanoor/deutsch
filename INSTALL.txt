SIEBEN TAGE DEUTSCH - phone app (iPhone and Android)

Latest version: includes the Job tab (full-time plan with tests after every item, topic, day and week).

1. PUT IT ONLINE (on your PC)
   New repo: github.com -> New repository "deutsch" (Public) -> "uploading an existing file".
   Already have the repo: open it -> Add file -> Upload files.
   Drag in ALL these files: index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png
   (same names replace the old ones) -> Commit changes.
   First time only: Settings -> Pages -> Branch "main", "/ (root)" -> Save.
   Wait 1-2 minutes. Link: https://YOUR-USERNAME.github.io/deutsch/

2. INSTALL
   iPhone: open the link in Safari -> Share -> Add to Home Screen -> Add.
   Android: open the link in Chrome -> menu (three dots) -> Install app (or Add to Home screen).
   Open it once while online. After that it works offline.

3. ALREADY INSTALLED? GET THE UPDATE
   Open the app while online, close it completely, open it again.
   You should see the first tab "Job - Full-time plan".

4. FIRST-TIME SETTINGS
   Microphone: tap Allow when asked.
   iPhone: Settings -> Siri on, and Settings -> General -> Keyboard -> Enable Dictation.
           German voice: Settings -> Accessibility -> Spoken Content -> Voices -> German.
   Android: Settings -> Text-to-speech -> Google engine -> Language Deutsch.

Progress is saved on each phone separately.
